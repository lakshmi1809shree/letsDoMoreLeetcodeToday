# Let's Do More Leetcode Today 🚀

A personal collection of solutions to [LeetCode](https://leetcode.com/) problems, organized one folder per problem. The goal of this repo is simple: solve a little more, every day.

## 📂 Structure

Each problem lives in its own folder, named `<problem-number>-<problem-slug>`, matching the problem's title on LeetCode. For example:

```
letsDoMoreLeetcodeToday/
├── 22-generate-parentheses/
├── 35-search-insert-position/
├── 79-word-search/
├── 104-maximum-depth-of-binary-tree/
├── 106-construct-binary-tree-from-inorder-and-postorder-traversal/
├── 110-balanced-binary-tree/
├── 148-sort-list/
├── 185-department-top-three-salaries/
├── 198-house-robber/
├── 226-invert-binary-tree/
├── 585-investments-in-2016/
├── 602-friend-requests-ii-who-has-the-most-friends/
├── 745-find-smallest-letter-greater-than-target/
├── 792-binary-search/
├── 948-sort-an-array/
├── 1116-maximum-level-sum-of-a-binary-tree/
├── 1452-restaurant-growth/
├── 1476-count-negative-numbers-in-a-sorted-matrix/
├── 1522-stone-game-iii/
├── 1664-find-users-with-valid-e-mails/
├── 3561-remove-methods-from-project/
├── 3626-smallest-divisible-digit-product-i/
├── 3705-find-the-largest-almost-missing-integer/
├── 4107-find-missing-elements/
└── ...
```

Topics covered span arrays, binary trees, linked lists, sorting, dynamic programming, binary search, backtracking, and SQL (database) problems.

## 🧭 How to use this repo

1. Browse the folder for the problem you're interested in — folder names match the LeetCode problem number and title.
2. Open the solution file inside to see the approach.
3. Feel free to fork or clone the repo to track your own progress alongside it:

   ```bash
   git clone https://github.com/lakshmi1809shree/letsDoMoreLeetcodeToday.git
   ```
